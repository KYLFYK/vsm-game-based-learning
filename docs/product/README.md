# Продукт — обзор

Агенты берут отсюда термины, роли и бизнес-правила, чтобы не выдумывать их.
Пока раздел не заполнен, любое продуктовое решение — вопрос к пользователю,
а не догадка.

## Концепция

ВСМ («Высокоскоростная магистраль») — концессионер проекта строительства
высокоскоростной железнодорожной магистрали. Платформа — игровое обучение
для сотрудников компании, в первую очередь проводников: они проходят
обучение в игровой форме, получают достижения, сравнивают результаты с
коллегами и весело проводят время за обучением.

## Термины

| Термин | Определение |
|--------|-------------|
| ВСМ — `VSM` | Высокоскоростная магистраль; компания-концессионер проекта её строительства |
| Сценарий — `Scenario` | Нелинейная история в форме визуальной новеллы; единица прохождения и оценки. Детали — [flows/scenario-run.md](flows/scenario-run.md) |
| Курс — `Course` | Упорядоченный список сценариев |
| Персонаж — `Character` | Фиксированный набор: наставники, пассажиры, невидимый автор |
| Шкала — `Meter` | Показатель сценария: лояльность пассажира, рейтинг безопасности |
| Попытка — `Attempt` | Одно прохождение сценария с результатом и журналом решений |
| Тема — `Topic` | Тег компетенции сценария и решения; основа разбора и рекомендаций |

Правило: термин из этой таблицы используется в коде, docs и UI одинаково;
английское имя сущности для кода фиксируется рядом (например,
«Заказ — `Order`»).

## Роли

Подробно — [roles.md](roles.md). Каждая следующая роль включает
возможности предыдущей.

| Роль | Короткое описание |
|------|-------------------|
| Сотрудник | Проходит курсы и ситуации, следит за прогрессом, получает достижения, сравнивает результаты с коллегами |
| Модератор | Собирает курсы и назначает их сотрудникам |
| Админ | Назначает модераторов, управляет компаниями, депо, бригадами и их составом |

## Внешние интеграции

Не определено — заполняется по мере появления требований.

## Как заполнять

1. Концепция и термины — первыми: от них зависят имена в `src/types`.
2. Роли — до первого guard'а в роутинге.
3. Сценарии — по одному файлу в [flows/](flows/README.md) на флоу; каждая
   фича client ссылается на свой флоу из [../client/features/](../client/features/README.md).
4. Раздел не превышает 200 строк: крупные темы уходят в подпапки со своим
   `README.md`.
