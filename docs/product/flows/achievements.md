# Достижения

## Цель

Сотрудник видит полученные достижения и весь каталог с условиями
получения: что уже есть и к чему стремиться.

## Роли

Сотрудник — смотрит свои и все достижения.

## Шаги

1. «Достижения» в шапке → страница с табом «Мои»: полученные, новые
   первыми, с датой получения.
2. Наведение или фокус на карточке → описание достижения.
3. Таб «Все» → весь каталог: полученные с датой, неполученные притушены
   с меткой «Не получено»; у каждого — «Как получить».
4. Нет ни одного достижения → в «Моих» пояснение и переход ко «Всем».

## Состояния и переходы

| Состояние | Что видно |
|-----------|-----------|
| Не получено | Картинка притушена, метка «Не получено» |
| Получено | Картинка в цвете, «Получено дд.мм.гггг» |

## Ограничения и правила

- Правила начисления не определены: сейчас только UI, полученные — заглушка.
  Условия в каталоге — текст для сотрудника, не исполняемые правила.
- Можно ли получить достижение повторно, не определено; дата — момент
  получения.
