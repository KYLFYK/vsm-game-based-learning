# Планы работ

Планы фич, декомпозированных на несколько задач. План живёт, пока фича в
работе, и задаёт очерёдность шагов. Точечные задачи планами не оформляются.

## Правила

- Один план = один файл `<kebab-case>.md` в этой папке + строка в списке
  активных.
- **Один шаг = одна задача**: самостоятельный результат, обновление docs и
  контур проверки (`yarn lint && yarn format:check && yarn test && yarn build`)
  внутри шага, не «потом».
- Чекбокс шага отмечается в той же задаче, где шаг выполнен.
- Решения из обсуждения фичи фиксируются в разделе «Принятые решения».
- Решение изменилось — план правится в той же задаче.
- Лимит 200 строк: крупный план разбивается на файлы по этапам с индексом.
- После завершения фичи файл удаляется, строка из списка снимается.

## Шаблон плана

```
# План: <название фичи>

Одно-два предложения: что появится после выполнения плана.

## Принятые решения

- Ключевые решения из обсуждения и их причины.

## Этап 1 — <название>

- [ ] **1.1 <Шаг>**: что сделать, какие файлы и слои затронуты.
  Docs: какие файлы docs/ обновить.
- [ ] **1.2 …**

## Этап 2 — <название>

- [ ] **2.1 …**

## Связанные файлы

- Ссылки на разделы docs/, задействованные в плане.
```
