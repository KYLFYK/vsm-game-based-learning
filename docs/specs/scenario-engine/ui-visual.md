# Визуальный язык сценария

Стиль игровых экранов: сел-шейдинг / комикс, «постер». Минимализм по
форме, яркость по цвету: плоские заливки, толстый чёрный контур, жёсткие
цветные тени без размытия, лёгкие наклоны плашек. Акценты — красный и
тёмно-синий. Структура экранов — [ui.md](ui.md).

## Где применяется

| Экран | Стиль |
|-------|-------|
| Заставка, сцена, HUD, финал (`scenario-player`) | Полностью |
| Карточки каталога на главной | Карточка и кнопка в стиле, `AppLayout` без изменений |
| Остальное приложение | Не меняется |

Фоны и портреты — текущие заглушки из `public/`; их перерисовка — шаг 7.2.

## Шрифты

- **Unbounded** (OFL) — вариативный шрифт, один файл на подмножество
  (cyrillic, latin) покрывает диапазон начертаний 800–900; файлы `woff2`
  в `public/fonts/` вместе с `OFL.txt`. `@font-face` с
  `font-display: swap` — в `global-style.ts`, `preload` подмножества
  cyrillic — в `index.html`.
- Unbounded — заголовки, HUD, номера вариантов, кнопки, штамп, имена;
  верхний регистр.
- Текст реплик, описаний и вариантов — системный `fontFamily`: длинный
  текст читается легче.

## Экраны

- **Заставка**: `ComicBackdrop Intro`; слева столбцом — плашка темы
  (чёрная, наклон), название на красной плашке крупно (Unbounded 900),
  описание, чипы лимита и порогов (белые, тень `redSm`), «Начать»
  (`Primary`, `Lg`). В углу — «К сценариям» (`Secondary`, `Sm`).
- **Сцена**: фон, `ComicBackdrop Scene`, слоты, облако, варианты, HUD.
- **Финал**: сцена без вариантов; `Stamp` сверху по центру, «К отчёту»
  (`Primary`, `Lg`) снизу по центру.

## Движение

| Что | Как | Длительность |
|-----|-----|--------------|
| Облако реплики | «pop»: масштаб 0.92 → 1 и прозрачность | `durations.pop` |
| Заливка шкалы | `width` | `durations.meter` |
| Дельта шкалы | Всплытие вверх и исчезновение | `durations.delta` |
| Штамп | «Удар»: масштаб 1.4 → 1, прозрачность 0 → 1 | `durations.stamp` |
| «Горящий» таймер | Пульсация масштаба 1 → 1.06 | 1 с, бесконечно |
| Нажатие кнопки | Сдвиг к тени | `durations.press` |

При `prefers-reduced-motion: reduce` анимации и переходы выключены,
дельта шкалы показывается без движения.
