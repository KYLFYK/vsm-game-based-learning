# Спецификации

Детальные описания подсистем, написанные по утверждённому плану из
[../plans/](../plans/README.md) до начала реализации. План отвечает «что и
в каком порядке», спецификация — «как именно»: типы, экшены, селекторы,
правила, критерии приёмки.

## Правила

- Одна спецификация = папка `<kebab-case>/` с `README.md`-индексом и
  файлами по темам; каждый файл до 200 строк.
- Спецификация не дублирует план и продуктовые правила, а ссылается на
  них; факт живёт в одном месте.
- Код пишется по спецификации; расхождение, найденное в реализации,
  правится в спецификации в той же задаче.
- После завершения фичи устоявшиеся решения переезжают в `docs/client/`
  и `docs/product/`, папка спецификации удаляется вместе с планом.
