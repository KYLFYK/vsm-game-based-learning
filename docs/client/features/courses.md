# Курсы и результаты

## Что делает

Список курсов с прогрессом, страница курса со сценариями по порядку,
статусом каждого по лучшей попытке и историей попыток с переходом в
отчёт.

## Маршруты

- `/courses` → `CoursesPage` (`course-list`, в `AppLayout`).
- `/courses/:courseId` → `CoursePage` (`course-view`, в `AppLayout`).

Пункт «Курсы» — в навигации `AppLayout`, кнопка «Курсы» — на главной.

## Файлы

- `pages/courses/`, `pages/course/` — страницы.
- `containers/course-list/` — `CourseList`: карточки курсов, «Зачтено N
  из M» или «Курс пройден», «Открыть».
- `containers/course-view/`:
  - `course-view.tsx` — данные, прогресс, «Курс не найден», список;
  - `course-scenario.tsx` — карточка сценария: номер, метка статуса,
    описание, лучшая попытка, «Играть» / «Пройти ещё раз»;
  - `attempt-history.tsx` — «История попыток (N)» в `<details>`: дата,
    итог, балл, время, метка «Лучшая», «Открыть ▸» на отчёт;
  - `course-view-model.ts` — подписи статусов, `playLabel`, `nextToPlay`.
- `utils/scenario-engine/best-attempt.ts`, `course-progress.ts` —
  лучшая попытка, статус сценария, прогресс курса
  ([../scenario-engine.md](../scenario-engine.md#лучшая-попытка)).
- `utils/route-links.ts` — ссылки с search-параметром `course`.

## Поток (step-by-step)

1. «Курсы» в шапке или на главной → список курсов с прогрессом.
2. «Открыть» → курс: сценарии по порядку со статусом «Не начат»,
   «Зачтено» или «Не зачтено».
3. Главная кнопка — у первого незачтённого сценария; «Играть» ведёт на
   `SCENARIO?course=<id>`.
4. Из сценария «◂ К курсу» на заставке и «Выйти» в HUD возвращают на
   курс; финал открывает отчёт с тем же `course`.
5. В отчёте «К курсу» возвращает на курс; статус и история обновлены.
6. «История попыток» на карточке → «Открыть ▸» → отчёт попытки с `course`.

## API

HTTP-запросов нет: `useGetCoursesQuery`, `useGetCourseQuery`,
`useGetScenariosQuery`, `useGetAttemptsQuery({})` на `queryFn`
([../api.md](../api.md)).

## Зависимости / гочи

- Статус и прогресс считаются по всем попыткам сценария, а не только по
  начатым из курса: сценарий один и тот же.
- История показывает все попытки сценария, новые первыми (порядок
  `getAttempts`).
- Хранилище попыток недоступно — курсы показываются, сценарии «не
  начаты».
- Сценарий курса без сводки в каталоге не показывается; бандл этого не
  допускает (`assertCourses`).
- Курс завершён, когда у каждого сценария есть попытка `passed`; пустой
  курс завершённым не считается.
- Каталог сценариев на главной остаётся: на него ведут рекомендации и
  «К сценариям» без курса.
